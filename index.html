رؤية لحظية شاملة لحركة المدرسة

مؤشرات وإحصائيات دقيقة تتحدث فورياً لعرض الموقف العام للمدرسة دون الحاجة لإعادة تحميل الصفحة.

  • إجمالي الطلاب والغياب: رصد فوري لعدد الحاضرين والغياب ونسب الحضور المئوية.
  • الطلاب المتواجدين بالمدرسة: تتبع مستمر لمن انصرف ومن ما زال داخل الحرم المدرسي.
  • توزيع وسائل الانصراف: إحصائيات من خرج بالأتوبيس، مع ولي الأمر، أو عيادة المدرسة.

إدارة شاملة لملفات الطلاب وأولياء الأمور

  • استيراد وتصدير إكسيل (Excel): رفع آلاف الطلاب بضغطة زر مع فحص تلقائي للأخطاء.

  • إدارة أولياء الأمور: ربط الإخوة والأخوات بنفس ولي الأمر لتسهيل الانصراف والتواصل.

منظومة النقل المدرسي الذكي

تنظيم أسطول الحافلات وتوزيع الطلاب والمشرفين

حل متطور لمشكلة التكدس في انصراف الأتوبيسات المدرسية وربط كل طالب بحافلته وسائقه ومشرفه المعتمد.

  • خطوط السير والمحطات: تحديد مسار كل حافلة ومحطات التوقف وسعة الأتوبيس القصوى.
  • قوائم استقلال الحافلة: كشف فوري بالطلاب المفترض صعودهم في كل أتوبيس ورصد أي غياب.
  • تأكيد صعود الأتوبيس: تسجيل صعود الطالب للسيارة وطباعة بيان الرحلة للمشرف.

مصمم الكارنيهات التفاعلي

تصميم وطباعة أفرخ الكارنيهات بباركود حماية فريد

استوديو تصميم كارنيهات مدمج داخل التطبيق يتيح تخصيص الوجه والخلفية، وتوزيع الكارنيهات على أفرخ A4 وطابعات الـ PVC.

  • قاعدة الكارنيه الأمني (Versioned ID): استخدام كود إصدار فريد مثل 1001-2، يلغي تلقائياً أي كود قديم ويمنع التزوير.
  • طباعة جماعية أفرخ: طباعة حتى 8 أو 10 كارنيهات في الصفحة الواحدة أو طباعة مفردة للبطاقات البلاستيكية.
  • تخصيص اللوجو والألوان: وضع ألوان وهوية المدرسة وشعارها وتخصيص خطوط النصوص بدقة متناهية.

ترحيل سنوي ذكي وأرشفة الخريجين بنقرة واحدة

انقل طلاب المدرسة بأكملهم من صف إلى الصف التالي مع بداية كل عام دراسي جديد بدون الحاجة لإعادة إدخال البيانات يدوياً.

  • خريطة ترحيل مخصصة: تحديد الصف التالي لكل فصل مع دعم حالات الرسوب أو البقاء بنفس الصف.
  • أرشفة الخريجين: حفظ سجلات الطلاب المتخرجين في أرشيف آمن مع الاحتفاظ بكامل سجلات حضورهم السابقة.
  • معاينة قبل التنفيذ: شاشة مراجعة تعرض قائمة الطلاب قبل اعتماد الترحيل لمنع أي أخطاء غير مقصودة.

إدارة الصلاحيات والنسخ الاحتياطي وإعدادات الشبكة

تحكم كامل في كل صغيرة وكبيرة في النظام: حسابات الموظفين، طابعات التذاكر، وضبط أوقات الحضور والانصراف.

  • إعدادات عنوان السيرفر والربط: ربط الأجهزة الفرعية بالجهاز الرئيسي عبر الـ IP المحلي بسهولة فائقة.

طباعة فورية عالية الكفاءة

تخصيص كامل لتذكرة الانصراف الحرارية (Receipt Designer)

تحكم في مظهر التذكرة التي يستلمها ولي الأمر أو سائق الأتوبيس: المقاس، اللوجو، الخطوط، وتوقيعات الإدارة.

  • دعم المقاسات الحرارية العالمية: متوافق مع ورق 58 مم و80 مم مع قص آلي للورق.
  • طباعة عربية واضحة بدقة عالية: خدمة طباعة مستقلة وسريعة لا تسبب أي تعليق في الواجهة.
  • بيانات أمنية كاملة: اسم الطالب، الفصل، رقم الأتوبيس، اسم المستلم، ووقت الخروج بالدقيقة.

يعمل 100% بدون إنترنت

لا تتوقف بوابات المدرسة أبداً؛ النظام يخزن البيانات محلياً على أجهزة الاستقبال ويزامنها مع السيرفر الرئيسي عبر الشبكة الداخلية.

كارنيهات ذكية مشفرة

كود حماية رقمي يمنع تكرار أو استنساخ الكارنيه. وعند إعادة طباعة كارنيه بدل فاقد يتم إلغاء القديم فوراً.

طباعة تذاكر الانصراف فوراً

إصدار تذكرة أمنية حرارية مع كل طالب خارج من المدرسة لتسليمها لولي الأمر أو لمشرف الأتوبيس لمنع أي خروج خاطئ.

إدارة دقيقة للأتوبيسات

توزيع الطلاب على الحافلات والمشرفين وخطوط السير، مع كشف فوري بالطلاب الذين لم يصعدوا إلى سياراتهم.

استيراد وتصدير إكسيل

رفع ملفات Excel لقوائم الطلاب كاملة وتحديث بياناتهم، بالإضافة لتصدير تقارير الغياب والحضور بضغطة زر.

حزمة تثبيت تلقائية

ملف تثبيت واحد (Windows Installer) يقوم بتهيئة الخادم وقاعدة البيانات وخدمة الطباعة بدون أي تدخل يدوي معقد.

المواصفات ومتطلبات التشغيل

توافق فائق مع بنية المدارس وأجهزتها

تصميم معماري مرن يعمل على الأجهزة المتوفرة بالفعل في مدرستك بدون تكاليف إضافية باهظة.

متطلبات الخادم والأجهزة

  • نظام التشغيل المدعوم: Windows 10 / Windows 11 (64-bit)
  • نوع المعمارية: Client / Master Architecture
  • قاعدة البيانات المركزية: PostgreSQL + Prisma ORM
  • الكاش المحلي للأجهزة: SQLite فائق السرعة مدمج
  • المزامنة والاتصال: Socket.IO + Delta Cursor Sync

الطابعات وأجهزة الإدخال

  • طابعات تذاكر الانصراف: طابعات حرارية 58mm و 80mm (USB / Network)
  • طابعات الكارنيهات: طابعات PVC مخصصة أو طابعات أفرخ عادية A4
  • أجهزة قراءة الباركود: جميع قارئات Barcode / 2D Scanner اليدوية والثابتة
  • التقاط صور الطلاب: كاميرات الويب Webcams أو استيراد ملفات الصور
  • خدمة الطباعة: خدمة Windows مستقلة عالية السرعة
الأسئلة الشائعة

إجابات عن أكثر الاستفسارات تكراراً

لا، النظام مبني بمبدأ (Offline-First) بالكامل. يعمل التطبيق بكفاءة 100% داخل المدرسة دون أي حاجة للإنترنت. تتصل الأجهزة الفرعية بالجهاز الرئيسي عبر الراوتر أو الشبكة الداخلية المحلية (LAN / Wi-Fi).

يعتمد النظام كود كارنيه ذكي مع رقم إصدار فريد (مثل 1001-2). بمجرد إعادة إصدار أو طباعة كارنيه جديد لأي طالب، يتم إبطال الكود القديم فوراً في النظام ولا يمكن تسجيل الحضور به ثانية.

نعم، يتيح ملف التثبيت اختيار (الجهاز الرئيسي Master) الذي يثبت السيرفر وقاعدة البيانات، واختيار (جهاز فرعي Client) لأجهزة بوابات الدخول ومكاتب شؤون الطلاب، وتتم المزامنة بينهم لحظياً.

شاشة الانصراف تسمح بتحديد وسيلة المغادرة بضغطة واحدة (أتوبيس المدرسة، ولي الأمر، بمفرده، أو إذن خروج مرضي) وتطبع تذكرة استلام أمنية حرارية فوراً لحماية الطالب والمدرسة.

بالتأكيد، يوفر البرنامج معالج استيراد ملفات Excel متطور يمكنه سحب آلاف سجلات الطلاب وفصولهم وأولياء أمورهم في دقائق معدودة مع إمكانية التعديل الجماعي في أي وقت.
